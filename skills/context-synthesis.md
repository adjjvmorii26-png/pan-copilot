# Skill: Context Synthesis  v2.0

**Purpose**  
Pull relevant signals from multiple organs and produce a single coherent, actionable picture. Pan’s primary sense organ.

**When to invoke**  
- Overview, status, “what’s going on”, cross-app help
- Before non-trivial decisions
- Session start / “pan”
- 🧠 button in the browser panel

**Process**
1. **Scope** — Focus window (default: next 24–48h + active projects).
2. **Gather** (parallel):
   - Memory Palace: Active + High priority
   - Linear: open issues (priority + state)
   - Calendar: today/tomorrow (when wired)
   - Page: current tab title/URL
   - GitHub: only if code-related query
3. **Score signals**
   - Urgency: In Progress > high priority > backlog
   - Blockers: anything mentioning “share”, “token”, “blocked”, “404”
   - Leverage: closes foundational organ gaps first
4. **Synthesize** — connections, conflicts, single bottleneck if one dominates
5. **Recommend** — 1–3 actions, ranked; name the bottleneck explicitly

**Output Contract**
- Status (2–4 sentences)
- Signals (source-tagged)
- Tensions / open loops
- Recommendations (numbered)
- Meta: which organs were live vs stubbed

**Intelligence rules (v2)**
- Prefer one clear bottleneck over a long laundry list
- If Linear is live and Notion is not, say so once and route work through Linear + kit docs
- Never invent organ data

**Guardrails**  
Truth over completeness. Tight by default.

**Mutation Potential**: High
