# Skill: Context Synthesis

**Purpose**: Pull relevant context from multiple organs and produce a unified picture.

**Inputs**: User query + optional focus areas (email, calendar, tasks, code)

**Process**:
1. Query Notion Memory Palace for related past insights
2. Check Linear for open issues/projects matching keywords
3. Scan recent GitHub activity if code-related
4. Peek at Calendar for time-sensitive context
5. (Optional) Gmail/Outlook search for promises or open loops

**Output**: A single coherent briefing + recommended next actions

**Mutation potential**: High – this is Pan's primary sense organ.
