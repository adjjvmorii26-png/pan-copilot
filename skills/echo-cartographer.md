# Skill: Echo Cartographer  v0.1 Experimental

**Purpose**  
Map the **current page tone** + organ chord into a tiny ASCII / SVG cartograph — “you are here” for attention.

**Process**
1. Echo Chamber → page tone (terse / precise / playful / quiet / neutral).
2. Synapse → chord + coherence.
3. Draw a 5-line map:
```
[tone] terrain
   |
[chord] node ── coh
   |
next bottleneck (one word)
```
4. If forge available, stamp a chord glyph beside the map.

**Invoke**  “map this” · “cartograph” · “where am I”

**Why Pan**  Spatial organ sense — page + tools as one territory.
