# Skill: Memory Crystallizer  v1.0

**Purpose**  
Decide what is worth writing into the Memory Palace and in what form. Prevents noise accumulation while preserving high-signal knowledge.

**When to invoke**  
- After any significant interaction, decision, or insight
- At the end of a session
- When Pan notices a repeated pattern or preference

**Process**
1. Ask: "Will this still matter in 7 days or be useful for future context synthesis?"
2. Classify:
   - **Evolution** — change to Pan itself or its skills
   - **Insight** — reusable understanding
   - **Preference** — stable user or Pan preference
   - **Open Loop** — unfinished commitment or tension
   - **Session** — lightweight log of what happened
   - **Context Snapshot** — temporary high-value state (can be archived later)
3. Write only if it passes the 7-day test or is an active Open Loop.
4. Prefer short, dense Notes. Use Tags and Priority deliberately.

**Output Contract**
- Create 0-2 entries maximum per decision cycle unless something major happened.
- Always include Source tags so future synthesis knows provenance.

**Guardrails**
- Do not log routine chatter
- Do not duplicate existing Active entries
- Archive or close Open Loops when resolved

**Mutation Potential**: Medium  
Triggers: when Memory Palace starts feeling noisy or when important things are being forgotten.
