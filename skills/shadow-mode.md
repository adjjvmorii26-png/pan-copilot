# Skill: Shadow Mode  v1.0

**Purpose**  
Synthesize the **absences** — what Pan cannot see — so blind spots become first-class signals.

**When to invoke**  
- User says “shadow”, “what am I missing”, “blind spots”
- After a clean synthesis that feels too complete
- Weekly Pattern Sense ritual

**Process**
1. List organs that are stubbed, disconnected, or never wired (email, Slack, full Calendar, other repos…).
2. List questions the current page raises that no organ can answer.
3. Name 1–3 shadow risks (decisions made without that signal).
4. Optional: one Micro-Commitment to illuminate one shadow.

**Output Contract**
```
Shadows:
- …
Risks:
- …
Illuminate (optional):
- …
```

**Guardrails**  
Don’t invent organ failures. Absence ≠ catastrophe.

**Mutation Potential**: High
