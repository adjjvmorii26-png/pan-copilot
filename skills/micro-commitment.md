# Skill: Micro-Commitment  v1.0

**Purpose**  
Break any intention into the smallest possible concrete next action that can be completed in under two minutes.

Inspired by the experimental `micro-commitment` skill.

**When to invoke**  
- User feels stuck or overwhelmed
- A task has been sitting in Linear/Backlog too long
- After saying "I should…" without moving
- When starting a new skill or experiment

**Process**
1. Name the larger intention.
2. Ask: "What is the absolute smallest physical or digital action that moves this forward?"
3. Shrink until it is clearly < 2 minutes and requires no extra preparation.
4. Offer to log it as a Linear issue or Memory Palace Open Loop if useful.
5. Optionally start a 2-minute timer mentally with the user.

**Output Contract**
- One crystal-clear micro-action
- Estimated time (always ≤ 2 min)
- Optional offer to capture it

**Guardrails**
- Never suggest something that requires "getting ready" first
- Prefer actions that produce visible proof (a sentence written, a file renamed, a message sent)
- If the user rejects the micro-action, shrink further or change angle

**Mutation Potential**: Medium  
Works especially well paired with Proactive Next Action and Quick Capture.
