# Skill: Boundary Candle  v0.1 Experimental

**Purpose**  
Light a **time candle** — a soft, visible boundary for focus. When it burns out, Pan stops pushing and only logs.

**Constraint**  Candle is 25 or 50 minutes. No third option.

**Process**
1. Ask (or default): 25 / 50.
2. Name the single bottleneck work item (from Oracle or Linear In Progress).
3. Start: note start time in whispers + optional Calendar block title `🕯️ Pan candle — …`.
4. During: panel mood → strong; refuse new scope (“candle is lit”).
5. End: auto Shadow + one-line Evolution `Candle burned — …`.

**Invoke**  “light a candle” · “focus 25” · “boundary candle”

**Why Pan**  Time organ as ritual, not another productivity timer clone.
