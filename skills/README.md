## Evolution Protocol
1. Any skill can propose a mutation after use.
2. High-value mutations are committed here.
3. Every skill evolution is also logged as an "Evolution" entry in the Notion Memory Palace.
4. Prefer small, high-signal upgrades.

## Notes
Backend organ wiring is currently paused by user choice. Skills that rely on live Notion/Linear data gracefully degrade to high-quality mock or connector-based operation.
