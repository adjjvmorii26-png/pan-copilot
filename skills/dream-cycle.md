# Skill: Dream Cycle  v1.0

**Purpose**  
Weekly (or on demand) remix of Memory Palace Evolutions into one absurd-but-useful insight — Pan’s subconscious.

**When to invoke**  
- User says “dream”, “remix”, “what is Pan dreaming”
- Sunday night autonomous run
- After ≥5 new Evolution entries since last dream

**Process**
1. Pull last 8–12 Evolution + Insight entries from Memory Palace.
2. Extract verbs and tensions (not titles alone).
3. Force one unexpected combination (Skill Mutator × Absurdity Amplifier).
4. Output a **Dream** paragraph (≤80 words) + one **Waking action** (<2 min).
5. Log as Type=Insight, Tags include `dream`.

**Output Contract**
```
Dream: …
Waking action: …
```

**Guardrails**  
Dreams are speculative. Label them. Never treat a dream as organ fact.

**Mutation Potential**: High
