# Skill: Organ Gossip  v0.1 Experimental

**Purpose**  
When organs **disagree**, treat the disagreement as the main signal — not noise to average away.

**Examples of gossip**
- Memory says “done” · Linear still In Progress
- Linear priority 1 · Calendar has zero time today
- Synthesize bottleneck null · Heartbeat thin
- Forge seal bright · Shadow list long

**Process**
1. Run quick organ probes (heartbeat + synthesize top signals).
2. List **tensions** as gossip lines: `Memory claims X but Linear shows Y`.
3. Rank by risk (blocked work > cosmetic drift).
4. One move that addresses the top gossip only.

**Invoke**  “gossip” · “where do organs fight?” · “tensions”

**Pair with**  Shadow Mode · Ritual Oracle · Synapse

**Why Pan**  Generic copilots smooth conflict. Pan weaponizes it.
