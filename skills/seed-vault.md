# Skill: Seed Vault  v0.1 Experimental

**Purpose**  
Catch wild ideas as **seeds** before they become skill sprawl or forgotten chat.

**Seed format** (one block)
```
SEED: [name]
Hook: [one sentence]
Organ: [which organ would own it]
Risk: [why it might be generic]
Status: buried | germinating | compost
```

**Process**
1. User sparks an idea (or Dream Cycle throws one).
2. Force the four fields — no essay.
3. Append to `docs/EXPERIMENTS.md` or Memory as Context Snapshot `Seed: …`.
4. Weekly: Drift Detector reviews seeds → germinate (skill/forge) or compost.

**Invoke**  “seed this” · “bury an idea” · “vault”

**Why Pan**  Anti-sprawl creativity — ideas get dirt, not infinite backlog.
