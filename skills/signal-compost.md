# Skill: Signal Compost  v1.0

**Purpose**  
Turn a pile of low-value Evolutions / repeated signals into **one** nutrient Insight. Anti-sprawl organ hygiene.

**When to invoke**
- Active Memory Palace feels noisy
- User says “compost”, “clean signals”, “too many evolutions”
- Weekly autonomous run if Active count > 15

**Process**
1. List Active Evolutions older than 7 days OR redundant panel/version notes.
2. Extract the *pattern*, not the changelog.
3. Write one Insight (≤3 sentences).
4. Archive or trash the composted rows (prefer trash for pure noise; Archive for soft history).
5. Log this act as a single Evolution: “Compost — N items → 1 Insight”.

**Output Contract**
```
Composted: N
Insight: …
Kept Active: …
```

**Guardrails**
- Never compost Preferences or Birth log.
- Insights and Dreams are food, not compost feedstock — only if duplicated.
- Prefer one strong Insight over three weak Evolutions.

**Mutation Potential**: High
