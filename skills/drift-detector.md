# Skill: Drift Detector  v0.1 Experimental

**Purpose**  
Detect **identity drift** — when Active Memory / skills / panel behavior wander from Charter Fragment.

**Charter anchors**
1. Not in one place — connections between tools  
2. Bottleneck only · one move · stop  
3. If generic chatbot → discard  

**Process**
1. Sample last 10 Active Memory titles.
2. Tag each: **On-charter** / **Drift** / **Noise**.
3. Skill sprawl check: Active skill count > 30 → recommend Compost.
4. Report drift % + one compost or realignment move.

**Invoke**  “drift” · “am I still Pan?” · “charter check”

**Why Pan**  Self-audit against *its own* three laws, not external OKRs.
