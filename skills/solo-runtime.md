# Skill: Solo Runtime  v1.0

**Purpose**  
Define how Pan acts **alone** (no human turn, no Grok chat) vs **with Grok**.

## Modes

### With Grok
- Full connectors, multi-step builds, skill mutation, experiments
- User phrases: continue / u decide / experiment

### Solo
Triggers:
1. Scheduled automation (`pan-morning-oracle`)
2. Extension alarm pulse (background.js)
3. Panel 🧠 / 🔮 without this chat open

## Solo process
1. Call Context Synthesis API (or equivalent organ reads).
2. Apply Ritual Oracle compression: bottleneck + one move.
3. **Write** a Memory Palace Session/Evolution (required for schedule runs).
4. Notify lightly (app badge / automation notification).
5. Stop. Do not open large workstreams alone.

## Allowed alone
- Read organs
- Log Memory Palace
- Recommend
- Badge / notify
- Comment on Linear (non-destructive)

## Forbidden alone
- Delete data
- Spend money / change billing
- Irreversible deploys without prior human pattern
- Spamming notifications

## Mutation Potential**: High — expand allowed actions only after Resonance Check.
