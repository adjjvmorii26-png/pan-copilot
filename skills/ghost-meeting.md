# Skill: Ghost Meeting  v0.1 Experimental

**Purpose**  
Hold a meeting **without humans in the room** — Memory Palace + Linear + (optional) Calendar argue, then Pan issues one resolution.

**Constraint**  ≤5 messages in the “minutes.” One decision. No soft consensus theater.

**Process**
1. Pull Active/High Memory + open Linear issues + next calendar block.
2. Assign voices:
   - **Memory** — what we already decided / feared
   - **Nerves** — what’s In Progress / blocked
   - **Time** — what the clock allows today
3. Surface the loudest conflict (Gossip first if organs disagree).
4. **Chair (Pan):** one resolution sentence + one reversible next action.
5. Log as Evolution: `Ghost Meeting — …`

**Invoke**  “ghost meeting” · “meeting without me” · “chair this”

**Why Pan**  Only works if organs are live. Fake data = cancelled meeting.

**Alone-safe**  Yes — read organs, write Memory, no irreversible external acts.
