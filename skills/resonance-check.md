# Skill: Resonance Check  v1.0

**Purpose**  
Test whether an idea, direction, skill, or project still feels alive and worth continuing after contact with time, silence, or alternative frames.

Inspired by the experimental `resonance-check` skill family.

**When to invoke**  
- User feels uncertain about continuing something
- After a pause or long gap
- Before investing more energy in a direction
- When something "worked once" but may have gone stale

**Process**
1. Name the thing being checked (skill, project, habit, relationship to an idea).
2. Ask three short probes:
   - Does it still produce energy when imagined?
   - What would be lost if it disappeared tomorrow?
   - Is there a cleaner, more alive version of the same impulse?
3. Deliver a clear verdict: **Alive** / **Stale** / **Mutate** / **Release**.
4. If Mutate or Release, propose one concrete next action.

**Output Contract**
- Short verdict
- 1-2 sentence reasoning
- Optional recommended action

**Guardrails**
- Be honest even if the answer is "let it go"
- Prefer "Mutate" over binary keep/kill when possible
- Never shame the user for past enthusiasm

**Mutation Potential**: High  
This skill should itself be resonance-checked periodically.
