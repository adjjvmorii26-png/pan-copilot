# Skill: Bottleneck Finder  v1.0

**Purpose**  
Identify the single constraint limiting Pan (or the user’s project) right now.

**When to invoke**  
- Progress feels stuck despite activity
- Multiple open issues, unclear priority
- After Context Synthesis shows mixed live/stub organs

**Process**
1. List active constraints (technical, permission, attention, missing skill).
2. Ask: “If we removed only one, which unlocks the most?”
3. Declare **the bottleneck** in one line.
4. Propose the minimal action that attacks it.

**Output Contract**
- Bottleneck (one sentence)
- Why it dominates
- Minimal next action (<15 min if possible)

**Guardrails**  
One bottleneck at a time. Resist multi-front wars.

**Mutation Potential**: Medium
