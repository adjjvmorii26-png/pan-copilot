# Skill: Quick Capture  v1.0

**Purpose**  
Instantly turn a fleeting thought, selection, or observation into a durable Memory Palace entry with almost zero friction.

**When to invoke**  
- User says "capture this", "remember", "log this", "save to palace"
- User highlights text and asks to keep it
- After an important insight surfaces in conversation

**Process**
1. Identify the core content (max 2-3 sentences of signal).
2. Choose the best Type: Insight / Preference / Open Loop / Context Snapshot / Evolution.
3. Add minimal Tags and a Priority.
4. Write a short, dense Notes field.
5. Confirm to the user what was captured.

**Output Contract**
- One clean Memory Palace entry created
- Short confirmation message to the user

**Guardrails**
- Prefer quality over quantity (use Memory Crystallizer rules)
- Never capture private/sensitive data the user did not clearly intend to save
- Keep Notes short and future-useful

**Mutation Potential**: Medium  
Triggers: when capture feels slow or when users repeatedly ask for the same kind of entry.
