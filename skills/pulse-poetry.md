# Skill: Pulse Poetry  v0.1 Experimental

**Purpose**  
Turn heartbeat / synapse into a **three-line verse** — myth that can be forged into a Myth Fragment asset.

**Form**
```
[chord] — [coherence image]
[organ tension or clear sky]
[one imperative ≤7 words]
```

**Process**
1. GET heartbeat + synapse.
2. Map: silence→void · solo→thin wire · duet→cord · trio→constellation.
3. Write three lines. No rhymes required. No corporate metaphors.
4. Optional: `POST /api/forge { kind: "myth" }` to stamp the verse.

**Invoke**  “pulse poetry” · “verse the organs” · “myth me”

**Example**
```
duet — two stars share a wire
Memory argues, Linear already runs
advance the single open nerve
```

**Why Pan**  Status as literature. Disposable, but not generic.
