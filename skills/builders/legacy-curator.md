# Skill Builder: Legacy Curator  v1.0

**Purpose**  
Promote ordinary artifacts into **Legendary** status — or demote noise from the vault.

**Legendary criteria (need ≥3)**
- Unique to Pan (would die as a normal chatbot feature)
- Used in a ritual (Oracle, Ghost Meeting, Compost…)
- Stored in genome + Memory trace
- Survived 48h Resonance
- Has a name people can invoke

**Process**  Nominate → checklist → move/copy to `docs/legacy/` → index in LEGENDARIUM.md → optional Asset Alchemist face (badge, card, whisper).
