# Skill Builder: Skill Breeder  v1.0

**Purpose**  
Spawn a new skill from two parents (crossover) or one parent (mutation). Meta-builder for the skill genome.

**Inputs**
- Parent A path, Parent B path (optional)
- Constraint (one sentence that forces originality)
- Name for offspring

**Spell**
1. Read both parents’ Purpose + Process + Guardrails.
2. Keep the sharper Purpose; merge Process only where non-redundant.
3. Add one *strange* step the parents lack (from EXPERIMENTS or Absurdity).
4. Write `skills/{name}.md` with version v0.1 Experimental.
5. Log Evolution; run Resonance in 48h.

**Output**  Offspring skill file + one-line DNA (e.g. `Oracle × Shadow → Blindspot Oracle`).

**Guardrails**  No generic “be helpful.” Prefer fewer skills over sprawl — compost if Active skills > 30.
