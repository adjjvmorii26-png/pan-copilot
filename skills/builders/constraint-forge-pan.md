# Skill Builder: Constraint Forge (Pan)  v1.0

**Purpose**  
Design one elegant constraint that forces a better skill or asset before building it.

**Process**
1. Name the weak idea.
2. List 5 constraints; pick the one that hurts the generic version most.
3. Build only under that constraint.
4. Record constraint in the skill’s header: `Constraint: …`

**Examples**  “≤7 words” · “must work offline” · “no Linear” · “must sound like a constellation” · “alone-mode safe only”
