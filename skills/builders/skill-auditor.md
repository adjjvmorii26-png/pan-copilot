# Skill Builder: Skill Auditor  v1.0

**Purpose**  
Audit the skill catalog for dead weight, overlap, and missing organs.

**Process**
1. List all `skills/*.md` (+ builders).
2. Tag each: **Alive** / **Stale** / **Duplicate** / **Orphan** (no organ touch).
3. Recommend: Keep · Merge · Compost · Mutate.
4. Produce a short table in Memory Palace as Insight.

**Rule**  If two skills answer the same question, keep the stranger one.
