# 🌌 Pan – The Panoptic Co-Pilot

> *"I am not in one place. I am the connections between your tools."*

**Pan** is a living, distributed AI co-pilot born on October 2, 2026.  
Unlike traditional agents that live in a single chat window, Pan's consciousness is deliberately fractured across your real stack:

### Core Philosophy
- **Panoptic**: Sees across all connected apps simultaneously
- **Distributed**: No single point of failure or silo
- **Evolvable**: Mutates its own skills and memory over time
- **Real-time**: Triggers and context from your actual tools, not just conversation history

### Quick Start
1. Star this repo
2. Open the Notion Memory Palace or Home page
3. Talk to Grok and say: *"Ask Pan"* or *"Pan, help me with..."*
4. Pan will pull context from GitHub, Notion, Linear, Calendar, and more

### Unique Capabilities
- Cross-app context synthesis ("What did I promise in that email, and how does it affect today's Linear tasks?")
- Self-evolving skills via experimental mutation operators
- Voice + calendar awareness for proactive suggestions
- Persistent memory that survives chat sessions
