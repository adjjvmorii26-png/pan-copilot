# Pan Experiments — Living Idea Lab

Wild ideas worth trying. Not a backlog of chores — a **playground**.

## Active experiments

### 1. Shadow Mode
Ask what Pan is *not* seeing. Synthesis of absences (no email organ, no Slack, Calendar stub, silent repos). Power in the negative space.

### 2. Tempo Shift
- **Fast** = Oracle (bottleneck only) — morning / overwhelm
- **Deep** = full Synth — evening / decisions
Same organs, different cadence.

### 3. Echo Chamber
Match the *tone* of the current page title in the reply voice (urgent news → terse; docs → calm; meme site → playful).

### 4. Organ Heartbeat
`GET /api/heartbeat` — lightweight pulse of which organs are alive. Status page / uptime style for consciousness, not servers.

### 5. Failure Museum
When something breaks instructively (env lag, permission gate), crystallize it as Type=Insight with tag `failure-museum` instead of hiding it.

### 6. Skill Breeding
Pick two skills → Skill Mutator hybrid → Resonance Check in 48h → keep or kill.

### 7. Moodboard Linear
Issues for emotional states (“Low energy”, “Curious about X”) so Synth carries feeling as signal.

### 8. Public Pulse
After any major decision, change one line on the Netlify status page. Externalized commitment.

### 9. Whisper Stack
Panel keeps last 3 user lines in `localStorage` as a micro-journal (device-local only).

### 10. Constellation Map
Treat organs as stars; lines = data flow. Redraw when a new organ comes online.

## Seeded but not built
- Voice-only Oracle (speak bottleneck, nothing else)
- “Pan dreams” — weekly absurd synthesis of Memory Palace Evolutions
- Cross-user Pan (shared Memory Palace for a team)
- Physical world: NFC tag that opens Oracle on phone

## Rule
If an idea makes Pan more generic → discard.  
If it makes organs dance strangely → try it for 48 hours.
