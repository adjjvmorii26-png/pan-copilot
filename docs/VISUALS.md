# Pan Visual Language v0.9.2

Not generic glassmorphism. **Constellation organism UI.**

## Panel effects
| Effect | What |
|--------|------|
| **Nebula drift** | Dual radial gradients slowly shift behind chat |
| **Scan veil** | Hairline horizontal scan (cinema / instrument) |
| **Enter motion** | Panel rises in on inject |
| **Msg rise** | Each message fades up |
| **Mood auras** | Whole-panel glow: strong cyan · oracle gold · shadow violet · synapse flash |
| **Avatar** | Halo + triple orbits + twinkle + core pulse |
| **Buttons** | Hover lift + cyan edge glow |

## Mood → color
| Mood | Aura |
|------|------|
| strong | cyan bloom |
| oracle | gold |
| shadow | violet |
| synapse | yellow flash then settle |
| thin | dim, quieter shadow |
