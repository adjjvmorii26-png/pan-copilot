# Creative & Unconventional Uses of Pan

Pan is not only a task co-pilot. It is a **distributed sense organ**. These modes exploit that.

## Ritual modes

| Mode | How | Why it’s weird/useful |
|------|-----|------------------------|
| Bottleneck Oracle | 🧠 → read only `bottleneck` + rec #1 | Forces single-constraint living |
| Dual-Lens | Synth then Absurdity Amplifier | Stereo thinking |
| Resonance Veto | Resonance Check only | Blocks shiny but dead ideas |
| Evolution Archaeology | Weekly Memory Palace dig | Pattern Sense on your own history |
| Page Haunt | Select text → Micro-Commitment | Reading → action in <2 min |
| Moodboard Linear | Issues for energy/mood | Nervous system carries feeling |
| Skill Breeding | Mutate two skills into a hybrid | Evolution as play |
| Negative-Space Pilot | Name what Pan ignores | Power in deliberate absence |
| Public Pulse | Edit status page after decisions | Externalized commitment |
| Permission-Gate Journal | Log every “connect/share” friction | Bureaucracy as RPG |

## Experimental combos

1. **Oracle → Micro-Commitment** — bottleneck becomes a 90-second move.
2. **Haunt → Crystallizer** — one quote from the page enters Memory Palace as Insight.
3. **Breeding → Resonance** — new hybrid skill must pass Alive check in 48h or die.
4. **Moodboard → Synth** — emotional issues change what “In Progress” means.

## Anti-uses (also valid)

- **Silence day**: no Synth; only capture.
- **Stub worship**: leave Calendar stubbed on purpose; protect time from automation.
- **One-organ week**: only Linear, or only Memory Palace — feel the imbalance.

## Design rule

If a use case makes Pan *more like a generic chatbot*, discard it.  
If it makes the **organs** (GitHub / Notion / Linear / panel / deploy) dance in a new pattern, keep it.
